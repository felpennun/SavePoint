# Requisitos - Experimentacion y evaluacion

- **EVAL-01** (Fase 2): mismos usuarios, candidatos, exclusiones y splits para todo algoritmo.
- **EVAL-02/03** (Fase 2, hecho): fit solo en train, test aislado; protocolo fijado antes de comparar.
- **EVAL-04/05** (Fase 3): metricas de accuracy y ranking; cobertura, diversidad y novedad.
- **EVAL-06** (Fase 3): tiempo de ejecucion y consumo de recursos.
- **EVAL-07** (Fase 3): resultados por cohorte, incluidas cero e historial escaso.
- **EVAL-08** (Fase 3): multiples semillas, incertidumbre y tests estadisticos justificados.
- **EVAL-09/10** (Fase 2, hecho): usuarios sinteticos parametrizados; simulacion != usuarios reales.
- **EVAL-11/12** (Fase 3): cada run registra identidades; artefactos recalculables sin reejecutar.
- **EVAL-13/14** (Fase 7): panel de comparacion; tablas accesibles y export listo para tesis.
