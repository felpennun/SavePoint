# Requisitos - Datos y procedencia

- **DATA-01/02** (Fase 1, hecho): dataset estable y citable; version, licencia, URL,
  fecha, checksum.
- **DATA-03** (Fase 2, hecho): diccionario de datos e informe de calidad del corpus fijo.
- **DATA-04** (Fase 01.1, hecho): API de enriquecimiento elegida por comparacion
  documentada -> [[ADR-006 - IGDB como fuente a escala real]].
- **DATA-05** (Fase 2): cada valor enriquecido conserva fuente y fecha.
- **DATA-06** (Fase 2, hecho): los datos mutables de la API no alteran experimentos cerrados.
- **DATA-07** (Fase 2): reglas deterministas de reconciliacion de identificadores y conflictos.
- **DATA-08** (Fase 2, hecho): la evidencia explica elecciones, limitaciones y redistribucion.
