# Requisitos - Operaciones, calidad y entrega

- **OPS-01/02/03** (Fase 1, hecho): despliegue a Internet documentado; ejecucion
  local reproducible; modo demo offline lawful sin API.
- **OPS-04** (Fase 7): backup y recuperacion probados de PostgreSQL y artefactos.
- **OPS-05** (Fase 7): logs estructurados y estados de job observables sin datos sensibles.
- **QUAL-01** (Fase 7): tests unitarios, de integracion y de navegador de flujos criticos.
- **QUAL-02** (Fase 3): instalacion limpia reproduce experimentos y evidencia.
- **QUAL-03** (Fase 1, hecho): flujos nucleares responsive y WCAG 2.2 AA.
- **QUAL-04** (Fase 7): alternativas textuales o tabulares para graficos.
- **QUAL-05** (Fase 01.1): diseno visual product-grade.
