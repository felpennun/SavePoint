# Testing y calidad

pytest 9 + pytest-django (contra PostgreSQL, no SQLite); Hypothesis para
invariantes de ranking, cotas de metricas y round-trips de import; Vitest +
Testing Library en frontend; Playwright 1.62 para flujos E2E; axe-core en
Playwright para accesibilidad; Ruff + mypy/django-stubs; ESLint 10. QUAL-01 pide
tests unitarios, de integracion y de navegador para los flujos criticos.
