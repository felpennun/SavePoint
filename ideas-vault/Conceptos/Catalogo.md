# Catalogo

Coleccion navegable de obras de juego con ficha de detalle y procedencia
(CAT-03), identificadores canonicos independientes de la API de enriquecimiento
(CAT-04) y uso offline cuando la API no esta disponible (CAT-06). Paso de 150
juegos curados de Wikidata a cientos de miles de titulos de IGDB en la Fase 01.1.
