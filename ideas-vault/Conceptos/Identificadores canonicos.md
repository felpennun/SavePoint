# Identificadores canonicos

El catalogo usa identificadores de juego canonicos que no dependen de la API de
enriquecimiento (CAT-04): UUID interno mas `canonical_slug`, con QID de Wikidata
o `id` de IGDB conservados como identificadores externos en `SourceRecord`. Evita
acoplar la identidad del producto a una fuente concreta.
