# GSD

Flujo de trabajo de planificacion usado en el repo (`.planning/`, comandos
`gsd-*`). Estructura el proyecto en fases y planes verificables con commits
atomicos y estado sincronizado (`.planning/STATE.md`, `ROADMAP.md`,
`REQUIREMENTS.md`, `PROJECT.md`). Tras planificar una fase se crea una GitHub
Issue por `PLAN.md` activo, cerrada segun avanza la ejecucion.
