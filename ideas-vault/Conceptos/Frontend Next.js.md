# Frontend Next.js

Frontend Next.js 16 / React 19 / TypeScript 6 (strict) con App Router para SSR de
perfiles publicos y metadatos, mas interacciones ricas para coleccion y
dashboards. Sirve la UI e i18n (es/en) y hace de proxy same-origin al API.
Estilado con tokens de Tailwind CSS 4.
