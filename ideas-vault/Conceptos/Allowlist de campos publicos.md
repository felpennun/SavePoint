# Allowlist de campos publicos

Las proyecciones publicas usan una lista explicita de campos permitidos (PRIV-01)
y no pueden filtrar datos privados de propiedad o notas. Es el mismo patron de
allowlist de respuesta que aplican las vistas de recomendaciones para que un
cambio futuro en un DTO no ensanche el contrato del cable.
