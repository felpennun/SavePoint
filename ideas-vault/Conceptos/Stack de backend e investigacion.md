# Stack de backend e investigacion

Python 3.13; Django 5.2.17 LTS; DRF 3.18; psycopg 3. Investigacion: NumPy 2.5,
SciPy 1.18 (matrices dispersas), pandas 3.0 (solo en fronteras de datos),
scikit-learn 1.9 (TF-IDF/one-hot, similitud coseno, splitting), implicit 0.7
(ALS/BPR, variante experimental), Optuna 4 (busqueda de hiperparametros con
sampler sembrado), MLflow 3.15 (tracking de experimentos). Sin recomendadores
neuronales por defecto; sin entrenar dentro de peticiones web.
