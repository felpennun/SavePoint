# Stack de frontend

Next.js 16.2; React 19.2; TypeScript 6 strict; Node 24 LTS; Tailwind CSS 4.3.
TanStack Query para estado de servidor en cliente; React Hook Form + Zod para
formularios accesibles (la validacion de backend sigue siendo autoritativa);
Recharts para graficos del panel, exportando siempre los datos subyacentes.
