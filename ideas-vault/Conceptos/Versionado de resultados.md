# Versionado de resultados

Todo resultado de recomendacion publicado conserva las versiones de modelo,
features y datos de entrada usadas (REC-09), y cada ejecucion del harness
registra identidades de codigo, entorno, dataset, split, semillas, parametros,
modelo y metricas (EVAL-11), sin alias mutables. Es la base de que los
[[Artefacto de evaluacion reproducible|artefactos]] se puedan recalcular sin
reejecutar el modelo (EVAL-12).
