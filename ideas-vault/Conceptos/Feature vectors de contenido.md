# Feature vectors de contenido

Modelo de features de contenido con cache `WorkFeatureVector` (Plan 02-10):
representacion de cada obra (generos y otros metadatos) que alimenta al
recomendador de contenido. Se calcula offline y se persiste; no se entrena ni
consulta dentro de una peticion HTTP.
