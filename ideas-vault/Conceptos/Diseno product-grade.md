# Diseno product-grade

La densidad visual, tipografia y tratamiento de imagen deben leerse como un
producto de catalogacion profesional (referencias del autor: Goodreads,
OpenCritic), no un layout utilitario minimo (QUAL-05). Se implementa con tokens
de diseno (Tailwind CSS 4), tema claro/oscuro y `ThemeToggle`, y se revisa con
un pase de UI dedicado en varias fases.
