# Mockups de SavePoint

Imágenes renderizadas de los lienzos de Claude Design que definieron la interfaz actual. Nada de esto lo usa la
aplicación al ejecutarse.

| Imagen | Qué muestra |
|---|---|
| `web.png` | **Web:** catálogo, recomendaciones, amistades, perfil y el resto de pantallas principales. |
| `ideas.png` | **Ideas:** tres direcciones para mejorar la interfaz (inicio con ranuras de guardado, catálogo como muro de portadas y recomendaciones explicables) y doce ideas de funciones ordenadas por coste. |
| `ideas-v2.png` | **Ideas v2:** segunda ronda, incluida la «Colección con listas». |
| `inicio.png` | **Inicio:** la página de inicio. |
| `identity.png` | **Identidad:** el sistema visual: concepto de marca, logotipo y variantes, paleta en tema claro y oscuro, tipografía, iconografía, portada de la memoria, diapositiva de defensa, componentes y tokens. |

Los lienzos originales y las maquetas HTML de la fase 01.1 no se publican. Las capturas de la aplicación real están
en `TFG/figures/`.
