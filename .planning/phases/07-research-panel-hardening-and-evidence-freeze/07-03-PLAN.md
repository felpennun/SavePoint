<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Navegador → middleware/Next | URL, cookies y viewport llegan sin confianza; middleware solo mejora UX. |
| Next SSR → API Django | La sesión se reenvía server-side y el backend decide si existe capability. |
| DTO API → DOM/descarga | Valores y nombres de enlace pueden contener texto hostil o datos no publicables. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-03-01 | Spoofing/Elevation of Privilege | route, layout, middleware | high | mitigate | Capability server-side, redirect solo para sesión ausente y 404 neutro desde API; la UI no concede acceso. |
| T-07-03-02 | Information Disclosure | evidence details/exports | high | mitigate | Consumir DTO saneado, no serializar en cliente, no renderizar per-user ni URLs privadas. |
| T-07-03-03 | XSS/Tampering | text, SVG, query params | medium | mitigate | React escaping, SVG con elementos y valores numéricos allowlisted del backend, GET form con opciones cerradas y tests de texto hostil. |
| T-07-03-04 | Denial of Service | responsive/table states | low | accept | La tabla usa scroll interno y límites del API; no se añade paginación client-side ni trabajo de cálculo. Riesgo residual cubierto por throttle backend. |
| T-07-03-SC | Tampering | frontend dependencies | high | mitigate | Se reutilizan dependencias bloqueadas y CSS/SVG existente; el pipeline de 07-02 revisa locks e imágenes. |
</threat_model>
