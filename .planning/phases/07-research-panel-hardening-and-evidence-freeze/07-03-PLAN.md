# Objetivo

Construir el panel web accesible para comparar runs y descargar datos de tesis.

## Tareas

1. Crear páginas SSR/client con tablas, filtros, estados loading/error/empty, explicación de métricas, comparación y exportación.
2. Añadir paridad ES/EN, navegación por teclado, focus return, targets 44px, responsive 320px/400% y axe; consumir únicamente DTOs del API.
