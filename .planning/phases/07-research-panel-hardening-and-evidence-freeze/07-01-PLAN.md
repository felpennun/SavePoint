# Objetivo

Exponer el panel de investigación mediante consultas paginadas y exportaciones trazables, sin ejecutar entrenamiento ni evaluación dentro de HTTP.

## Tareas

1. Implementar endpoints autenticados de runs, comparaciones, métricas, tiempos, artefactos y exportación CSV/JSON desde snapshots existentes.
2. Añadir permisos por rol, límites de tamaño, content disposition seguro, checksum y tests de no mutación, paginación y ausencia de secretos.

## Verificación

`docker compose -f infra/compose.yaml run --rm api pytest apps/api/evaluation/tests/test_phase7_api.py -q`; `manage.py check`; `makemigrations --check --dry-run`.

## Criterio de terminado

Un investigador autorizado puede consultar y exportar resultados congelados; cualquier usuario no autorizado recibe respuesta neutral y no se crean artefactos nuevos.
