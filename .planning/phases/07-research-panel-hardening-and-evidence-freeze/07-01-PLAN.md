## Trust Boundaries

| Boundary | Description |
|---|---|
| Navegador → API Django | Cookies, query parameters y cabeceras llegan desde un cliente no confiable. |
| Usuario Django → permiso de investigación | La identidad autenticada se traduce a permisos de servidor antes de consultar el snapshot. |
| API → descarga | DTO y Content-Disposition no deben reflejar datos controlados por el usuario. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-01-01 | Elevation of Privilege | `ResearchViewerPermission` | critical | mitigate | `has_perm` obligatorio en cada vista, 404 neutro para autenticados sin permiso y tests de matriz de roles. |
| T-07-01-02 | Information Disclosure | runs/comparison/artifacts | high | mitigate | Serializers manuales, snapshot allowlisted y exclusión de `per_user`, rutas y secretos; tests de respuesta. |
| T-07-01-03 | Injection | query parameters/export headers | high | mitigate | Parser allowlisted, ORM sin SQL construido con entrada y filename/MIME constantes. |
| T-07-01-04 | Denial of Service | endpoints research | medium | mitigate | ScopedRateThrottle, límites de filtros y no ejecución de trabajo de evaluación desde HTTP. |
| T-07-01-05 | Spoofing | session/capabilities | high | mitigate | Django SessionAuthentication y capabilities calculadas en `MeView`; la UI no concede acceso. |
| T-07-01-SC | Tampering | dependencias y locks | high | mitigate | No se instala ningún paquete nuevo; el scope `research` se verifica junto con los locks en los gates. |
</threat_model>
