# Objetivo

Cerrar la superficie administrativa y el hardening de aplicación con permisos, auditoría y controles de entrada.

## Tareas

1. Implementar administración autenticada de usuarios/catálogo/imports/jobs, con roles, ownership, confirmaciones y eventos de auditoría sin secretos.
2. Añadir/ajustar controles para inyección, XSS/CSRF, SSRF/redirecciones, rate limits, headers, errores neutrales, secretos y dependencias; cubrirlos con pytest.

## Verificación

`docker compose -f infra/compose.yaml run --rm api pytest apps/api/tests/test_phase7_security.py -q`; `scripts/check-secrets.ps1`; `scripts/check-dependencies.ps1`; `manage.py check --deploy`.

## Criterio de terminado

Las operaciones de administración son auditables y los ataques declarados fallan de forma segura sin revelar datos ni secretos.
