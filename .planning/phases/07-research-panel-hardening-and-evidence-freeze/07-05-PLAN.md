<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser credentials/host → Playwright | Credenciales y respuestas de demo entran en una prueba que puede generar trazas. |
| Frozen artifacts → generated evidence | Datos experimentales se transforman en salidas publicables y deben conservar identidad. |
| Launch gate → release/signoff | Resultados de comandos determinan si el demonstrator puede presentarse. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-05-01 | Information Disclosure | Playwright traces/evidence | critical | mitigate | Variables solo de proceso, redacción, revisión de artefactos y checks de secretos antes de signoff/publicación. |
| T-07-05-02 | Tampering | generator/manifest | high | mitigate | Hashes antes de lectura, inputs allowlisted, outputs deterministas y sentinel de no mutación del v15. |
| T-07-05-03 | Spoofing/Elevation | browser auth/admin | high | mitigate | Usuarios con grupos separados, pruebas de login/404/admin y API como autoridad. |
| T-07-05-04 | Repudiation | launch gate/signoff | medium | mitigate | Comandos, commit, entorno, hashes, resultado y limitaciones registrados en documentos versionados. |
| T-07-05-05 | Denial of Service | deployed smoke | medium | mitigate | Health/headers/timeouts, no trabajo de evaluación en HTTP y ejecución offline explícita. |
| T-07-05-SC | Tampering | release dependencies | high | mitigate | `check-dependencies`, locks, imágenes y `check-secrets` son gates bloqueantes; no se añaden paquetes. |
</threat_model>
