<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Upload del usuario → parser/import service | CSV, filenames y celdas no confiables pueden provocar writes, inyección o consumo excesivo. |
| Scripts operador → PostgreSQL/storage privado | Un path o dump mal elegido puede destruir/restaurar sobre el destino equivocado. |
| Jobs/imports → logs/evidencia | Estados y errores operativos no deben filtrar secretos o datos personales. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-04-01 | Tampering | import apply | high | mitigate | Digest de preview, revalidación, transaction.atomic, ownership por `request.user` y reglas de conflicto deterministas. |
| T-07-04-02 | Path Traversal/Denial of Service | backup/restore scripts | high | mitigate | Parámetros obligatorios, paths resueltos dentro del backup root, base temporal única y cleanup limitado al nombre creado. |
| T-07-04-03 | Information Disclosure | manifests/logs | high | mitigate | Campos allowlisted, redaction, dumps privados y checks de secretos antes de publicar evidencia. |
| T-07-04-04 | Repudiation | operation state | medium | mitigate | `operation_ref`, actor técnico, resultado y timestamps estructurados, además de AuditEvent del plan 07-02. |
| T-07-04-SC | Tampering | scripts and dependencies | high | mitigate | No hay instalación de paquetes; checks de locks, imágenes, scripts y manifiestos forman parte de la gate final. |
</threat_model>
