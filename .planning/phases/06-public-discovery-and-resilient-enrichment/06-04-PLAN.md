<threat_model>
**ASVS level:** 1 (L1)

**Mitigaciones obligatorias:** privacidad y fuga de datos se preservan consumiendo DTOs discriminados; IDOR y bloqueo se dejan decidir al backend en cada fetch; cooldown no se calcula como autoridad en cliente; CSRF usa same-origin y token; XSS se evita con nodos de texto escapados.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → Next.js | Cookies, rutas, query params, formularios y texto social son no confiables. |
| Next.js SSR → Django | Cookie forwarding y requests same-origin cruzan autenticación y privacidad. |
| API DTO → DOM | Alias, títulos, comentarios y mensajes deben renderizarse como texto y no HTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-04-01 | Information disclosure | SSR profile/list/message pages | critical | mitigate | El frontend consume DTOs discriminados, no precarga contenido social y trata 404/hidden con la misma vista genérica. |
| T-06-04-02 | Elevation / IDOR | Client routes and links | high | mitigate | Middleware solo hace guard grueso; cada API/SSR fetch vuelve a autorizar y nunca envía owner_id como autoridad. |
| T-06-04-03 | CSRF / Spoofing | SocialActions/Inbox mutations | high | mitigate | Reutilizar `client-api.ts`, `ensureCsrfToken`, same-origin credentials y tests de mutación sin token. |
| T-06-04-04 | XSS | Comments, bios, messages, aliases | high | mitigate | React text nodes, sin HTML crudo, límites server-side y tests con `e2e/fixtures/hostile.json`. |
| T-06-04-05 | Information disclosure | Badge and relationship status | medium | mitigate | Badge se obtiene solo para el usuario autenticado y siempre lleva etiqueta textual; no mostrar estado de terceros. |
| T-06-04-06 | Tampering / DoS | Query filters and cooldown UI | medium | mitigate | Query allowlist del backend, estado UI derivado de respuesta, cooldown aceptado solo por API y no por contador cliente. |
| T-06-04-07 | Availability | Mobile overflow/focus traps | low | mitigate | CSS reflow, scroll interno de popovers, targets 44px, Escape y focus return probados a 320px/400%. |
| T-06-04-SC | Tampering | Dependencias | low | mitigate | Reutilizar componentes first-party y paquetes ya fijados; cualquier instalación exige gate de legitimidad. |
</threat_model>
