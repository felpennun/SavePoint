<threat_model>
**ASVS level:** 1 (L1)

**Mitigaciones obligatorias:** privacidad y fuga de datos se verifican con DTOs allowlisted; IDOR exige autorización en cada URL; bloqueo revoca y oculta bilateralmente; cooldown se aplica con lock y tiempo server-side; CSRF requiere sesión protegida; XSS usa texto plano escapado.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser/URL → API social | Alias, slugs, comentarios, mensajes, cookies y CSRF son entrada no confiable. |
| API → PostgreSQL | Policy/service decide visibilidad y transiciones; DB aplica unicidad, FK y concurrencia. |
| API → proyección pública | DTOs allowlisted cruzan hacia actores con distintos permisos. |
| API → inbox privado | Mensajes y agregados solo se entregan al receptor autenticado. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-03-01 | Information disclosure | Profile/collection/list/comment projection | high | mitigate | Policy-first queryset y DTOs separados; pruebas de ausencia de datos privados e IDs para cinco actores. |
| T-06-03-02 | Elevation / IDOR | Direct URLs and APIs | critical | mitigate | Reautorizar en cada endpoint usando `request.user` + friendship/block; recurso oculto responde 404 genérico. |
| T-06-03-03 | Tampering | Block and relationship visibility | high | mitigate | Reutilizar transición block atómica de 06-01 y comprobar ambos sentidos antes de serializar. |
| T-06-03-04 | CSRF / Spoofing | Comments, requests, mark_read, recommend | high | mitigate | SessionAuthentication, CSRF por `client-api.ts`, métodos explícitos y tests sin token. |
| T-06-03-05 | Tampering / DoS | Recommendation cooldown | high | mitigate | Lock estable por pareja, `atomic()`, índice temporal, límites de cuerpo y tests antes/en/después de 7 días. |
| T-06-03-06 | XSS | Bio, comment, list name, message | high | mitigate | Validación de longitud, texto plano/escape, React sin HTML crudo y fixtures hostiles; no reflejar errores internos. |
| T-06-03-07 | Information disclosure | Inbox/badge | high | mitigate | Querysets derivados del receptor autenticado y agregados sin nombres/relaciones de terceros. |
| T-06-03-08 | Tampering | Public list slug | medium | mitigate | Slug generado server-side, unicidad por propietario, backfill idempotente y sin aceptar owner desde payload. |
| T-06-03-SC | Tampering | Dependencias | low | mitigate | No se añaden dependencias; cualquier instalación requiere gate de legitimidad. |
