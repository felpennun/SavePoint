<threat_model>
**ASVS level:** 1 (L1)

**Mitigaciones obligatorias:** privacidad y fuga de datos se prueban con respuestas uniformes; IDOR deriva el actor de `request.user`; bloqueo cancela y oculta en ambos sentidos; cooldown se serializa por pareja; CSRF usa `SessionAuthentication`; XSS usa DTOs de texto plano escapado.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → social API | Alias, identificadores de relación, cookies, CSRF y comandos son entrada no confiable. |
| Social API → PostgreSQL | El servicio decide actor/objetivo; constraints y transacciones hacen cumplir invariantes. |
| Social state → futuras proyecciones | Un bloqueo o amistad decide si otra superficie puede revelar datos. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-01-02 | Information disclosure | Búsqueda exacta y bloqueos | high | mitigate | Alias exacto, throttle, resultados uniformes y ocultación simétrica; no devolver directorio ni distinguir bloqueado. |
| T-06-01-03 | Tampering | Máquina de estados | high | mitigate | Servicios transaccionales, locks de pareja, `UniqueConstraint`/`CheckConstraint` y matriz reject/remove/block. |
