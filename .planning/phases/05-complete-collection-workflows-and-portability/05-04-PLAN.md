## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated browser → export endpoint | El navegador solicita un archivo y el backend decide qué filas pertenecen al usuario. |
| PostgreSQL → CSV serializer | Campos privados atraviesan una transformación de lectura con contrato explícito. |
| CSV file → spreadsheet application | Valores no confiables podrían interpretarse como fórmulas al abrirse. |
| Canonical docs/vault → future executor | Reconciliaciones de alcance deben evitar declarar trabajo diferido como hecho. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-04-01 | Elevation | Export endpoint | high | mitigate | `IsAuthenticated`, querysets de `request.user`, no user_id del cliente y tests A/B de aislamiento. |
| T-05-04-02 | Tampering | CSV cells | high | mitigate | Contrato de columnas, neutralización de `= + - @`, test de parseo/bytes e idempotencia. |
| T-05-04-03 | Information disclosure | Export/public DTO | high | mitigate | Allowlists positivas, exclusión explícita de secretos/IDs/datos terceros y revisión de cabecera/celdas. |
