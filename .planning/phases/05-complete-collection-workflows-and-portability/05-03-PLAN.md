<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → copy API | Metadatos de compra, moneda, precio, formato y conservación son entrada no confiable. |
| Copy service → PostgreSQL | El servicio mantiene relaciones y la base impide combinaciones físico/digital inválidas. |
| Owner data → public projection | Datos de compra/conservación cruzan solo la respuesta autenticada del propietario. |
