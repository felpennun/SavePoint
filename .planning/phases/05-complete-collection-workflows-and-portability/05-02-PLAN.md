    - Test 5: una excepción durante el reorder deja el orden anterior intacto; un usuario B no puede acceder a recursos privados de A y una lista pública solo expone nombre, obras y posiciones allowlisted.

|---|---|
| Browser → comment/list API | IDs de obra/lista/item, texto, nombre, visibilidad y orden son entrada no confiable. |

| Public profile/game detail → visitor | Solo comentarios/listas públicos y campos allowlisted cruzan la frontera. |
