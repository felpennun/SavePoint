<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → accounts API | Cookies, CSRF headers, alias, contraseña, biografía, avatar y UUIDs son entrada no confiable. |
| accounts API → PostgreSQL | El backend decide identidad, visibilidad y relaciones; la base aplica constraints. |
| Public profile → visitor | La respuesta pública cruza una frontera de divulgación y debe ser allowlisted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01-01 | Spoofing | Login/register/session | high | mitigate | Mantener Django sessions, hashing, CSRF pre-session, rotación de sesión, errores uniformes y `ScopedRateThrottle`; los tests de auth bloquean la tarea si falta alguno. |
| T-05-01-02 | Elevation | Profile/favorites endpoints | high | mitigate | `IsAuthenticated`, querysets y servicios derivados de `request.user`, constraints PostgreSQL y pruebas A/B contra IDOR. |
| T-05-01-03 | Information disclosure | PublicProfileView/build_public_profile | high | mitigate | Resolver `public/private` antes de consultar y construir diccionarios allowlisted; denylist recursiva y pruebas anónimas/B. |
| T-05-01-04 | Tampering | Avatar/profile text | medium | mitigate | URL HTTPS acotada sin fetch server-side, serializers estrictos, texto plano y pruebas de payloads hostiles. |
| T-05-01-SC | Tampering | Dependencias | low | mitigate | No se añaden paquetes; cualquier dependencia nueva detiene la ejecución y exige la auditoría de legitimidad del proyecto. |
</threat_model>
