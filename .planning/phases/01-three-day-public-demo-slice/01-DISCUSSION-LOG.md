## Demo Journey

| Question | Options considered | Selected |
|----------|--------------------|----------|
| Public landing | Homepage with login; example profile; catalogue | Realistic homepage with visible login |
| Controlled access | Normal form with visible demo credentials; demo button; profile selector | Normal form with visible demo credentials |
| Post-login destination | Dashboard; catalogue; collection | Catalogue |
| Guidance | Natural interface; discrete prompts; guided tour | Natural interface plus external presentation script |

**Notes:** The application must feel like a real public website rather than a laboratory shell.

---

## Initial Catalogue

| Question | Options considered | Selected |
|----------|--------------------|----------|
| Initial size | 100-300 curated; 1,000-5,000; maximum volume | 100-300 curated, scalable to thousands |
| Composition | Representative multiplatform; current popular; personal taste | Representative across eras, genres, and platforms |
| Covers | Rights-approved with placeholders; unrestricted remote; no real covers | Maximise rights-approved covers with attribution and placeholders |
| Provenance | Per game; global page; both | Both |
| Identity | Base game only; release per platform; hierarchy | Hierarchical work/release/edition/copy model |
| Language | Spanish plus original; locale fallback; English only | Spanish and English per user, with fallback |
| DLC | Exclude; independent expansions; all independent | Link DLC/expansions to base game, never independent backlog items |
| Search | Simple; tolerant; advanced | Tolerant bilingual search; advanced filters deferred |

**Notes:** The user explicitly wants the eventual catalogue to contain thousands of games and the maximum lawful cover coverage.

---

## Backlog and Inventory

| Question | Options considered | Selected |
|----------|--------------------|----------|
| Rating scale | Five stars/halves; 1-10/halves; 0-100 | Five stars with half-star increments |
| Status model | Current only; current plus history; simultaneous states | One current status plus dated history |
| Copy creation | Short form; full form; instant defaults | Short form: format, platform, edition |
| Cross-platform ratings | Per game; per platform; both | One rating/status per game, copies separate |

**Notes:** Preserve clean internal values and boundaries for later recommender work and possible version-level ratings.
