that subsequent plans (starting with 01-04 session tracer) can build upon
without creating missing infrastructure.

## Decisions Made

- **Type shims in `types/shims/`**: Next.js 16 calls `hasNecessaryDependencies` which resolves `@types/react/index.d.ts` and `@types/node/index.d.ts` from the project root. Adding them to the registry would require extending the dependency allowlist (a human-gated supply-chain decision). Instead, minimal ambient shims are committed under `types/shims/` and copied into `node_modules/@types/` at build time. This satisfies Next.js' file-presence check, keeps `check-dependencies.ps1` green, and leaves the allowlist unchanged.
- **Bind mount for migration generation**: `makemigrations` runs inside the container (Python 3.13 + Django 5.2.17 + psycopg3) but writes back to the host via `-v "${PWD}/apps/api:/workspace/apps/api"`. This avoids any host Python 3.14 mismatch and keeps files version-controlled.
- **`WORKDIR` and symlink**: The Dockerfile links `manage.py` to `/workspace/manage.py`; `PYTHONPATH=/workspace/apps/api` ensures all app imports resolve correctly.
