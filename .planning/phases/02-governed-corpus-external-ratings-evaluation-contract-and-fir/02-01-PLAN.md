<objective>
Convertir el import IGDB de ~312k obras en un **corpus gobernado, citable y versionado**:
una migración aditiva marca `GameWork.in_corpus` según las reglas estrictas de D-03 y la
allowlist de plataformas de D-01, y un comando `govern_corpus` idempotente emite el checksum
inmutable, el diccionario de datos y el informe de calidad / campos faltantes que exige DATA-03.

Purpose: es la base de toda la fase — los snapshots de rating (Plan 02-02), el recomendador
(Planes 02-10/02-11) y el harness de evaluación (Plan 02-08/02-13) leen siempre la vista
`governed_works(corpus_version)`.
Output: migración 0006, `catalogue/corpus.py`, comando `govern_corpus`, freeze doc + JSON,
suite de tests de integración.
</objective>
