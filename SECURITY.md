# Política de seguridad

SavePoint es un proyecto académico (Trabajo Fin de Grado) con una demostración pública en
<https://save-point-orpin.vercel.app>.

## Cómo informar de una vulnerabilidad

Usa los **avisos de seguridad privados** de GitHub: pestaña *Security* del repositorio → *Report a vulnerability*. Así el
informe llega solo al autor y no se hace público hasta que esté corregido. Por favor, no abras una issue pública con los
detalles de una vulnerabilidad.

Incluye, si puedes, qué has encontrado, cómo reproducirlo y qué impacto crees que tiene. Es un proyecto sin presupuesto ni
equipo, así que la respuesta puede tardar unos días.

## Alcance

- El código de este repositorio y la demostración desplegada.
- Las cuentas de demostración publicadas en el README son públicas a propósito y no contienen datos personales.
- Fuera de alcance: ataques de denegación de servicio, pruebas de carga y fuerza bruta contra la demostración, que usa
  niveles gratuitos de Vercel, Render y Neon.
